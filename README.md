# Nassau Candy Sales Analysis

## 📌 Project Overview

This project analyzes Nassau Candy sales data to understand overall sales
performance, product profitability, division-level performance, cost and
margin relationships, and profit concentration.

The project combines data analysis and visualization to transform raw sales
data into actionable business insights. An interactive dashboard is also
provided to explore the data dynamically.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall sales and profit performance
- Identify top-performing and most profitable products
- Compare performance across business divisions
- Evaluate product-level profit margins
- Identify low-margin products requiring attention
- Analyze the relationship between cost and sales
- Understand profit concentration across products
- Identify important business trends and patterns
